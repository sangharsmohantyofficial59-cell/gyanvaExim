# Enquiry sheet backup

Enquiries are stored in the Google Sheet configured for the Apps Script web app and are also emailed to the company inbox. Keep access to the spreadsheet and inbox restricted to authorised company users.

To make a manual backup, open the enquiry spreadsheet in Google Sheets and choose **File → Download → Microsoft Excel (.xlsx)** or **Comma-separated values (.csv)**. Store the downloaded file in the company's approved backup location and restrict access because it contains personal information. To restore, create or open a Google Sheet and use **File → Import** with the saved file.

Choose and document an appropriate backup schedule and retention period with the company owner. A spreadsheet download is a point-in-time copy; it does not automatically stay in sync with new enquiries.
